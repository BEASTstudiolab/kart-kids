# Available Skills (Slash Commands)

| Command | Purpose |
|---------|---------|
| `/game-start` | First-time onboarding — asks where you are, then guides you to the right workflow |
| `/game-design-review` | Review a game design document for completeness and consistency |
| `/game-code-review` | Architectural code review for a file or changeset |
| `/game-playtest-report` | Generate a structured playtest report template |
| `/game-balance-check` | Analyze game balance data and flag outliers |
| `/game-sprint-plan` | Generate or update a sprint plan |
| `/game-bug-report` | Create a structured bug report |
| `/game-architecture-decision` | Create an Architecture Decision Record (ADR) |
| `/game-asset-audit` | Audit assets for naming, sizing, and pipeline compliance |
| `/game-milestone-review` | Review milestone progress and generate status report |
| `/game-onboard` | Generate onboarding context for a new contributor or agent |
| `/game-prototype` | Scaffold a throwaway prototype to test a mechanic or technical approach |
| `/game-release-checklist` | Generate and validate a pre-release checklist for the current build |
| `/game-changelog` | Auto-generate changelog from git commits and sprint data |
| `/game-retrospective` | Run a structured sprint or milestone retrospective |
| `/game-estimate` | Produce a structured effort estimate with complexity and risk breakdown |
| `/game-hotfix` | Emergency fix workflow with audit trail, bypassing normal sprint process |
| `/game-tech-debt` | Scan, track, prioritize, and report on technical debt across the codebase |
| `/game-scope-check` | Analyze feature or sprint scope against original plan, flag scope creep |
| `/game-localize` | Localization workflow: scan for hardcoded strings, extract, validate translations |
| `/game-perf-profile` | Structured performance profiling with bottleneck identification and recommendations |
| `/game-project-stage-detect` | Automatically analyze project state, detect stage, identify gaps, and recommend next steps |
| `/game-reverse-document` | Generate design or architecture documents from existing implementation (works backwards from code) |
| `/game-team-combat` | Orchestrate combat team: game-designer + gameplay-programmer + ai-programmer + technical-artist + sound-designer + qa-tester |
| `/game-team-narrative` | Orchestrate narrative team: narrative-director + writer + world-builder + level-designer |
| `/game-team-ui` | Orchestrate UI team: ux-designer + ui-programmer + art-director |
| `/game-team-release` | Orchestrate release team: release-manager + qa-lead + devops-engineer + producer |
| `/game-team-polish` | Orchestrate polish team: performance-analyst + technical-artist + sound-designer + qa-tester |
| `/game-team-audio` | Orchestrate audio team: audio-director + sound-designer + technical-artist + gameplay-programmer |
| `/game-team-level` | Orchestrate level team: level-designer + narrative-director + world-builder + art-director + systems-designer + qa-tester |
| `/game-launch-checklist` | Complete launch readiness validation across all departments |
| `/game-patch-notes` | Generate player-facing patch notes from git history and internal data |
| `/game-brainstorm` | Guided ideation using professional studio methods (MDA, SDT, Bartle, verb-first) |
| `/game-gate-check` | Validate readiness to advance between development phases (PASS/CONCERNS/FAIL) |
| `/game-map-systems` | Decompose game concept into systems, map dependencies, prioritize design order, guide per-system GDDs |
| `/game-design-system` | Guided, section-by-section GDD authoring for a single game system with cross-referencing and incremental writing |
| `/game-setup-engine` | Configure engine + version, detect knowledge gaps, populate version-aware reference docs |
